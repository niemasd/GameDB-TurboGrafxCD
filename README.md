# GameDB-TurboGrafxCD
NEC TurboGrafx-CD, part of [GameDB](https://github.com/niemasd/GameDB).

## Structured Downloads
* **[`TurboGrafxCD.data.json`](https://github.com/niemasd/GameDB-TurboGrafxCD/releases/latest/download/TurboGrafxCD.data.json):** All data, structured in the JSON format
* **[`TurboGrafxCD.data.tsv`](https://github.com/niemasd/GameDB-TurboGrafxCD/releases/latest/download/TurboGrafxCD.data.tsv):** All data, structured in the TSV format
* **[`TurboGrafxCD.release_dates.pdf`](https://github.com/niemasd/GameDB-TurboGrafxCD/releases/latest/download/TurboGrafxCD.release_dates.pdf):** Histogram of release dates, stratified by region
* **[`TurboGrafxCD.titles.json`](https://github.com/niemasd/GameDB-TurboGrafxCD/releases/latest/download/TurboGrafxCD.titles.json):** Mapping of serial numbers to game titles, structured in the JSON format
